# 图片资源目录说明

本目录存放拾野茶集官网的全部图片素材，均为团队原创绘制的 SVG 矢量图，不包含任何第三方图片、水印或需要付费授权的素材，也不调用外部图床。

| 目录 / 文件 | 用途 |

## 全部素材由脚本生成

图片不是手工另存的文件，而是由项目根目录下的 `tools\gen-assets.js` 用代码绘制的，设计变量集中在 `tools/svg-lib.js` 的色板中。修改色板或图形后，在项目根目录下运行：

```powershell
cd <项目根目录>
node tools/gen-assets.js
```

即可重新生成全部 29 个素材文件，保证品牌配色与图形风格始终统一。

## 替换为真实照片的方法

课程答辩或后续运营时，如果拿到了真实产品照片，可以直接替换同名文件，页面无需改动：

1. 将照片裁切为 1:1（产品图）或 16:9（新闻图），建议宽度不小于 800px，单张体积控制在 300KB 以内。
2. 用相同文件名保存为 `.jpg` 或 `.png`，并同步修改 HTML 中对应的 `src` 后缀（例如 `p1-teacake.svg` 改为 `p1-teacake.jpg`）。
3. 保留图片的 `alt` 描述，替换后请检查描述与照片内容是否一致，这对搜索引擎与无障碍阅读都有帮助。

## 使用注意

- 图片均为原创绘制，可直接用于课程提交与教学展示。
- 若对外发布，请勿使用未授权字体或他人拍摄的照片。
- 二维码为图形占位，不是可扫描的真实二维码，正式运营时请替换为真实的企微与公众号活码。
