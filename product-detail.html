    产品优势

    为什么办公室抽屉里该放一盒茶粉

    把“想喝茶”和“不想洗茶具、等水烧开”之间的矛盾，用一支 3g 的茶粉解决。

    3 秒即溶 不用等

    无论冷水、温水还是气泡水，倒入后搅拌 3 秒即可饮用，不需要烧水、称茶、滤渣。

    原叶萃取 不是茶末

    原料是普洱景谷产区的大叶种原叶茶，低温萃取后冻干，保留茶多酚与香气，茶汤透亮不浑浊。

    0 糖 0 添加

    配料表只有茶叶萃取物，不加香精、白砂糖与植脂末，控糖人群也能放心喝。

    单支独立包装

    3g 一支带出门，通勤包、健身包、办公桌各放几支，撕开倒进瓶子就完成了。

    用户痛点

    想喝茶，却总是被这些小事劝退

    • 办公室没有条件：只有一台饮水机，洗茶具、滤茶渣都要跑去茶水间。
    • 夏天不想喝热的：冷泡茶要提前 4-8 小时准备，想喝的时候来不及。
    • 外面的瓶装茶太甜：看配料表全是糖与香精，喝起来有负担。
    • 买的散茶越喝越碎：拆开包装后香气衰减快，最后半包只能扔掉。
    • 出差行李不方便：茶具、滤网、茶叶罐加起来占地方，还容易潮。
    解决方式

    一支茶粉，把五个问题一起收掉

    • 撕开就能冲：1 支兑 200-300ml 水，冷水 3 秒即溶，不用烧水、称茶、滤渣。
    • 0 糖 0 添加：配料表只有茶叶萃取物，替代便利店瓶装茶饮，单次成本约 4.3 元。
    • 单支密封不返潮：每次用完一支，不会像散茶那样开封后香气快速衰减。
    • 不占地方：10 支装比一副茶具轻得多，出差、健身、露营都能带。
    • 口味自由：加牛奶变茶拿铁，加柠檬与冰块变冷萃柠檬茶，浓淡按水量调。
    如果你习惯慢泡原叶茶、看重叶底与香气层次，可以在产品中心选择古树生普饼茶或滇红金针；冻干茶粉解决的是“想喝茶但没条件泡”的场景。

    冲泡指南

    三种喝法，一张参数表

    包装内附冲泡卡，收到后照着做即可。口味浓淡按水量调整，不用刻意记克数。

    1. 撕开倒入杯中 沿缺口撕开单支包装，把茶粉倒入随行杯或玻璃杯，杯中有少量水也不影响溶解。
